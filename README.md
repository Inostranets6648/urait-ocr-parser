# Web Reader Vector OCR Extractor

![Python Version](https://img.shields.io/badge/python-3.11%20%7C%203.12-blue)
![License](https://img.shields.io/badge/license-MIT-green)

Автоматизированный инструмент на Python для извлечения, распознавания (OCR) и структурирования текста из защищенных веб-ридеров (на примере электронных библиотек), отображающих страницы в формате SVG-векторов и `canvas`.

## 💡 Назначение и Архитектура

Многие современные сервисы электронных книг защищают контент от выделения и копирования, отрисовывая страницы через сложную векторную графику (SVG), где текст конвертирован в геометрические контуры (`<path>`).

Инструмент решает эту проблему следующим образом:
1. **Network Interception (`Playwright`):** Запускает экземпляр браузера и перехватывает сетевые ответы (SVG-векторы) "на лету" при пролистывании.
2. **High-DPI Vector Rendering (`PyMuPDF`):** Распаковывает и рендерит векторный SVG в растровое изображение высокого разрешения (PNG) прямо в памяти без потери качества.
3. **Neural OCR (`Tesseract`):** Распознает русский и английский текст с помощью сверточных нейросетей (CNN + LSTM).
4. **Text Cleaning & Formatting:** Очищает текст от рваных переносов слов (дефисов на стыках строк) и восстанавливает структуру абзацев.
5. **Crash-Proof Streaming:** Выполняет потоковую запись каждой страницы сразу на диск, что защищает от потери данных при обработке объемов в 500+ страниц.
6. **Multi-Format Export:** Генерирует итоговые файлы `.docx`, `.pdf` (с полной поддержкой кириллицы) и `.txt`.

---

## 🛠️ Требования к системе

1. **Python** 3.11 или 3.12 (рекомендуется).
2. **Tesseract OCR** — программа для распознавания текста.
   * **Windows:** Скачайте инсталлятор с [Tesseract at UB Mannheim](https://github.com/UB-Mannheim/tesseract/wiki). 
   * **Важно:** При установке отметьте галочку **`Russian`** в разделе *Additional language data (download)*.

## 🚀 Быстрый старт

### 1. Клонирование репозитория
```bash
git clone [https://github.com/ВАШ_НИК/urait-ocr-parser.git](https://github.com/ВАШ_НИК/urait-ocr-parser.git)
cd urait-ocr-parser

```

### 2. Установка зависимостей Python

```bash
pip install -r requirements.txt
playwright install chromium

```

### 3. Запуск скрипта

```bash
python main.py

```

## 📖 Инструкция по использованию

1. Запустите `main.py` и укажите в консоли:
* URL книги или документа в ридере.
* Название папки для сохранения файлов (по умолчанию `output/`).
* Количество страниц для выгрузки (например, `500`).


2. В открывшемся окне браузера войдите в свой аккаунт (если требуется) и перейдите на страницу, с которой нужно начать выгрузку.
3. Вернитесь в консоль и нажмите **ENTER**.
4. Скрипт начнет автоматическое пролистывание со случайными интервалами (для защиты от блокировок) и постраничную запись текста на диск.

По окончании работы в папке назначения сформируются 3 файла: `extracted_book.txt`, `extracted_book.docx` и `extracted_book.pdf`.

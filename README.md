# Web Reader Vector OCR Extractor & Web-Book Generator

![Python Version](https://img.shields.io/badge/python-3.11%20%7C%203.12-blue)
![License](https://img.shields.io/badge/license-MIT-green)

Автоматизированный инструмент на Python для извлечения, распознавания (OCR), фильтрации графического шума и конвертации текста из защищенных веб-ридеров (на примере электронных библиотек) в удобные документы (`.docx`, `.pdf`, `.txt`) и интерактивный **HTML Web-ридер**.

---

## 💡 Назначение и Архитектура

Многие современные сервисы электронных книг защищают контент от выделения и копирования, отрисовывая страницы через сложную векторную графику (SVG), где текст конвертирован в геометрические контуры (`<path>`).

Инструмент решает эту проблему в два этапа:

### Этап 1. Извлечение и OCR (`main.py`)
1. **Network Interception (`Playwright`):** Запускает экземпляр браузера и перехватывает сетевые ответы (SVG-векторы) "на лету" при пролистывании.
2. **High-DPI Vector Rendering (`PyMuPDF`):** Распаковывает и рендерит векторный SVG в растровое изображение высокого разрешения (PNG) прямо в памяти без потери качества.
3. **Neural OCR (`Tesseract`):** Распознает русский и английский текст с помощью сверточных нейросетей (CNN + LSTM).
4. **Crash-Proof Streaming:** Выполняет потоковую запись каждой страницы сразу на диск, что защищает от потери данных при обработке объемов в 500+ страниц.
5. **Multi-Format Export:** Генерирует итоговые файлы `.docx`, `.pdf` (с полной поддержкой кириллицы) и `.txt`.

### Этап 2. Очистка и верстка Web-ридера (`make_html.py`)
1. **Heuristic Noise Filtering:** Алгоритмически удаляет «мусорные» строки, остатки рамок, осей координат и рваных подписей к схемам/таблицам, которые Tesseract ошибочно считывает с векторной графики.
2. **Document Structuring:** Автоматически распознает заголовки тем, глав, подразделов (например, `1.1`, `4.2`) и блоки страниц, оборачивая их в семантические HTML-теги.
3. **Adaptive Reading Interface:** Формирует автономный single-file HTML с типографикой, адаптированной под комфортное чтение с компьютеров, планшетов и смартфонов.

## 🛠️ Требования к системе

1. **Python** 3.11 или 3.12 (рекомендуется).
2. **Tesseract OCR** — программа для распознавания текста.
   * **Windows:** Скачайте инсталлятор с [Tesseract at UB Mannheim](https://github.com/UB-Mannheim/tesseract/wiki). 
   * **Важно:** При установке отметьте галочку **`Russian`** в разделе *Additional language data (download)*.

## 📖 Инструкция по использованию

### Шаг 1. Скачивание и распознавание книги

Запустите основной скрипт парсинга:

```bash
python main.py

```

1. Укажите URL книги и количество страниц для выгрузки (по умолчанию `500`).
2. В открывшемся окне браузера авторизуйтесь в аккаунте и перейдите на страницу, с которой нужно начать выгрузку.
3. Вернитесь в консоль и нажмите **ENTER**.
4. По окончании работы в папке `output/` сформируются файлы: `Full_Book.txt`, `Full_Book.docx` и `Full_Book.pdf`.

### Шаг 2. Генерация Web-ридера (HTML)

Для очистки текста от графического шума и создания красивого читаемого файла запустите:

```bash
python make_html.py

```

Скрипт обработает `output/Full_Book.txt` и создаст в той же папке файл **`Full_Book.html`**, который можно открыть в любом браузере или перенести на мобильное устройство.
